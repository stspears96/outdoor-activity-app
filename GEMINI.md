This repository contains a web application called "Outdoor activity suggester". Its primary purpose is to recommend local outdoor activities based on the user's location and real-time weather data. The application has two main functions: 1) A general activity recommender that scores activities like hiking, running, and picnics based on upcoming weather (temperature, wind, precipitation). 2) A highly sophisticated surf recommender that finds nearby surf spots from a local SQLite database and scores them in real-time based on live wind, wave, and swell conditions from multiple APIs (Open-Meteo and CDIP). This surf feature is the most complex and well-engineered part of the application, demonstrating advanced techniques like batched API calls, data source prioritization (CDIP over generic forecasts), and detailed, domain-specific scoring logic. The investigation was interrupted before a full analysis of the 'places' and 'trails' features, but they appear to be simpler functionalities that find nearby points of interest (like parks and trailheads) using an external API, likely OpenStreetMap.
